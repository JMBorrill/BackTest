## Invalid bearer token (collection request 4)

`POST /v1/backtests` -> **401**

```json
{
  "error": {
    "code": "unauthenticated",
    "message": "Bearer token invalid"
  }
}
```

Same status and same `code` as request 3. Only the message differs - which is what separates "not sending credentials" from "credentials are stale".

## Symbol containing a path

```json
{
  "error": {
    "code": "validation_failed",
    "message": "Request failed validation",
    "fields": [
      {
        "path": "symbol",
        "message": "String should match pattern '^[A-Za-z0-9._-]+$'"
      }
    ]
  }
}
```

Rejected by the schema, so it never reaches the code that builds a filename.
